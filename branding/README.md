# Edvio brand

| File | Use |
|---|---|
| `source/edvio-logo.webp` | Edvio logo (mark + wordmark): admin web header, login page, documents |
| `source/edvio-mark.webp` | Edvio mark: favicon, admin web icon, splash |
| `source/parent-app.webp` | Parent app icon (blue, family under a roof) |
| `source/teacher-app.webp` | Teacher app icon (green, teacher with a book and board) |
| `source/driver-app.webp` | Driver and bus staff app icon (orange, bus with driver) |

`source/` holds the logos as supplied. `png/*-icon-1024.png` are square, full-bleed 1024 px versions cut from them
(no white margin, shadow or rounded corners, with extra room around the symbol so Android and iOS masks don't clip it);
use those for launcher icons and store listings. `png/edvio-logo.png` is the logo as PNG, `png/overview.png` shows all.

The supplied files are about 1250 px raster images. For print or very large use, ask the designer for SVG versions.
